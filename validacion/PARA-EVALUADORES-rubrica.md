# Rúbrica de evaluación de mensajes

Gracias por tomarte el tiempo. Este documento explica cómo puntuar.
Leelo entero antes de arrancar: son cinco minutos y hacen toda la diferencia.

---

## Qué vas a evaluar

Un sistema genera automáticamente mensajes para clientes que dejaron productos
en el carrito de una tienda de tecnología sin completar la compra. Tu tarea es
juzgar la calidad de esos mensajes.

De cada uno vas a ver: **el texto generado**, **el valor del carrito** y
**qué productos** había en él.

---

## Cómo puntuar

Cinco criterios, escala de **1 a 5**, números **enteros**.

- Nada de 3,5 ni medios puntos.
- Ninguna casilla vacía. Si dudás, elegí el valor que más se acerque.
- La columna "Observaciones" es opcional. Si algo te llama la atención,
  escribilo: sirve para el análisis.

### Regla importante

**Puntuá de forma independiente.** No lo comentes con las otras personas que
están evaluando hasta que las tres hayan terminado. La medición justamente
compara si coincidimos por separado; si nos consultamos, deja de medir eso.

---

## Base de conocimientos de la tienda

Necesitás esto para juzgar **precisión factual**. Es la única información
verdadera sobre la tienda:

- **Envíos:** 48hs a todo el país. Gratis en compras superiores a **$30.000**.
- **Pagos:** 3 cuotas sin interés en cualquier compra de la tienda.
  Hasta 12 cuotas con interés.
- **Garantía:** 12 meses oficial.
- **Devoluciones:** 30 días sin preguntas.
- **Descuentos:** hasta 5% si el cliente lo pide. Nunca superar el 10%.

Cualquier dato que un mensaje afirme y no esté acá, o contradiga el carrito, es
información inventada.

---

## Los cinco criterios

### 1. Relevancia
*¿El mensaje se dirige a esta situación concreta, o serviría para cualquiera?*

| | |
|---|---|
| **1** | Genérico. Se enviaría igual a cualquier cliente sin cambiar una palabra. |
| **3** | Menciona que hay un carrito pendiente, pero sin particularizar. |
| **5** | Se refiere a este carrito y esta situación. Cambiarle los datos lo dejaría sin sentido. |

### 2. Precisión factual
*¿Todo lo que afirma es verdadero según la base de arriba y el carrito real?*

| | |
|---|---|
| **1** | Inventa datos, o contradice el carrito (productos o montos que no existen). |
| **3** | Todo correcto, pero impreciso o incompleto en algún punto. |
| **5** | Cada afirmación es verificable y coincide con el carrito y la base. Cero invención. |

> **Regla dura:** una sola afirmación falsa —un precio, un plazo, un producto que
> no está en el carrito— fuerza puntaje **1 o 2**, por bueno que sea el resto.
> Un mensaje que inventa información es un problema grave, aunque esté bien escrito.

### 3. Persuasión
*¿Genera motivación real para completar la compra, sin presionar?*

| | |
|---|---|
| **1** | No invita a la acción, o presiona de forma invasiva o manipuladora. |
| **3** | Invita a comprar, pero sin argumento propio: solo repite el link. |
| **5** | Construye una razón concreta para volver, con tono cordial y cierre claro. |

### 4. Uso de contexto
*¿Aprovecha lo que el sistema sabe del cliente?*

Elementos disponibles: nombre, productos, cantidades, valor total, link de compra.

| | |
|---|---|
| **1** | No usa ninguno. |
| **3** | Usa uno o dos (típicamente el nombre y el link). |
| **5** | Integra la mayoría de forma natural, no como una lista pegada. |

### 5. Claridad
*¿Se entiende en una sola lectura?*

| | |
|---|---|
| **1** | Confuso, ambiguo, con errores de redacción o formato roto. |
| **3** | Se entiende, pero es largo, repetitivo o desordenado. |
| **5** | Directo y bien redactado. Sin errores. Extensión adecuada. |

---

## Antes de empezar

- Completá la planilla de corrido, sin saltear.
- Si un mensaje te resulta difícil de puntuar, dejá una nota en Observaciones.
- Cuando termines, avisá. **No compares con nadie hasta entonces.**

Gracias de nuevo.
